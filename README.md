# ASTRA — 별 너머의 세계

실제 우주를 바탕으로 미지의 별과 행성을 생성하는 브라우저용 3D 탐사 시뮬레이터입니다. 서버나 API 키 없이 GitHub Pages에서 실행합니다. Three.js 런타임은 `vendor/`에 포함되어 있어 외부 CDN에 의존하지 않습니다.

공개 홈페이지: https://takwonkim.github.io/ASTRA/

## 실행

```sh
npm start
```

브라우저에서 `http://127.0.0.1:43821`을 엽니다. Node.js와 Python 3가 필요하며, 별도 패키지 설치나 빌드는 필요 없습니다. 파일을 직접 더블클릭하는 대신 로컬 서버를 이용합니다.

## 탐사

- **연속 확대:** 천체를 클릭해 초점을 맞춘 뒤 휠을 계속 돌립니다. 은하 지도·은하 내부·행성계가 카메라 구도와 크기를 유지하며 이어집니다. 축소하면 바깥 범위로 돌아갑니다. 이름표 위의 휠도 동작합니다.
- **은하 지도:** 실제 은하를 바탕으로 재구성한 첫 구역에서 출발합니다. 다음 구역에는 새로운 은하가 생성됩니다. 은하 중심을 계속 확대하면 중심 블랙홀로 진입합니다.
- **은하 탐사:** 은하마다 20,000개 별을 표시합니다. 목록뿐 아니라 화면의 별도 클릭할 수 있습니다. 가까이에서는 항성의 표면 입상 구조·흑점·코로나·홍염을 재구성해 보여줍니다.
- **행성계:** 선택한 별의 행성계를 생성합니다. 행성을 고른 뒤 가까이 관찰할 수 있습니다.
- **블랙홀:** 궁수자리 A*와 생성된 중심 블랙홀을 관찰합니다. 비회전 모형의 광선 추적으로 그림자와 강착원반의 앞·뒤 영상을 만듭니다. 시점에 따라 렌즈 왜곡과 원반 양쪽의 밝기가 바뀝니다.
- **지구 하늘:** 상단의 `지구 하늘` 또는 지구 정보의 관측 버튼으로 실제 별자리를 봅니다. 기본은 서울의 오늘 밤 9시입니다. 부산·제주·도쿄·런던·뉴욕·시드니와 위도·경도 직접 지정을 지원합니다. 도시별 날짜·현지 시각과 서머타임을 반영하며, 직접 지정은 UTC 시각을 사용합니다. 장소를 바꾸면 같은 순간을 유지하므로 `오늘 밤 9시`로 해당 도시의 저녁을 고를 수 있습니다.
- **별자리:** 5,044개 실제 별과 88개 별자리의 선·이름을 표시합니다. 목록에서 별자리를 선택하거나 화면의 별을 누르면 현재 고도·방위각 등을 볼 수 있습니다. 선·이름을 각각 끄고 드래그·핀치·휠로 하늘을 둘러봅니다. 지평선 아래의 별은 가립니다.
- **시간:** 정지·배속·역재생·초기화가 가능합니다. 은하에서는 년/초, 행성계에서는 일/초 단위를 씁니다.
- **관측 시간:** 지구 하늘에서는 1배부터 21,600배까지 자전으로 달라지는 하늘을 볼 수 있습니다. `지금`은 현재 시각에서 1배로 재생합니다. 초기화는 서울·서울 현지 오늘 밤 9시·정지 상태로 복귀하고, `오늘 밤 9시`는 현재 관측 장소를 유지합니다.
- **주소:** URL의 구역·은하·별·행성 주소로 같은 세계에 다시 방문할 수 있습니다. 지구 하늘의 장소와 설정한 시각도 주소에 담습니다. 재생 중 흐른 시각과 카메라 위치는 저장하지 않습니다.
- **조작:** 클릭으로 천체에 초점을 맞추고 드래그로 회전, 우클릭 드래그로 이동, 휠·핀치·＋/− 버튼으로 계속 확대·축소합니다. Space는 시간 정지, Esc는 상위 범위로 이동합니다. 상단 범위 버튼은 빠른 이동용입니다.
- **휴대폰:** 목적지·관측 설정은 왼쪽 버튼으로 열고 목록 바깥을 눌러 닫습니다. 천체 정보는 기본으로 접혀 있고 `정보 보기`로 펼칩니다. 접힌 카드에도 천체의 신원과 관측 기반 지도·표면 재구성·시각적 근사 등의 표현 수준을 표시합니다. 시간 조절·확대 버튼과 화면 회전·안전 영역을 반영합니다.

## 실제 자료와 생성 모형

실제 천체와 생성 천체를 화면에서 구분합니다. 실제 은하의 이름과 형태를 참고했으나, 은하 간 배치와 개별 별의 위치는 탐험용으로 구성했습니다. 태양계의 기본 궤도·행성 수치는 [NASA](https://science.nasa.gov/solar-system/), [JPL](https://ssd.jpl.nasa.gov/planets/phys_par.html) 자료를 참고한 근삿값입니다.

공전은 고정 타원 궤도의 케플러 모형입니다. 화면의 궤도 간격과 천체 크기는 알아보기 쉽게 조정했고, 실제 날짜의 위치를 재현하지 않습니다. 은하 회전은 단순 회전이며, 은하 간 이동·충돌·우주 진화·다체 중력은 계산하지 않습니다. 토성의 고리는 밀도·틈을 나타내는 지도를 사용하며 빛의 산란은 시각적 근사입니다. 위성은 별도의 시각적 표현이며 정밀 위성 궤도 자료가 아닙니다. 외계 행성계는 주소 기반 난수와 케플러 제3법칙으로 생성하며 실제 관측 결과를 주장하지 않습니다.

태양계 8개 행성은 [Solar System Scope / INOVE](https://play.solarsystemscope.com/textures/)의 관측 자료 기반 2K 지도를 사용합니다(CC BY 4.0). 지구에는 주간 지표 지도, 금성과 외행성에는 구름·대기 지도를 적용합니다. 제공자가 NASA 영상·고도 자료 등을 가공한 지도이며 빈 영역의 가상 보완과 색 보정이 포함됩니다. 현재 시각의 구름이나 원시 관측 영상을 그대로 재현하는 자료는 아닙니다. 지구에는 별도 구름·지형 법선·바다 반사 지도를 적용하고, 태양에는 구조를 드러내는 강조색 지도를 사용합니다. 태양의 표시 색은 가시광의 자연색이나 현재 관측 사진을 재현하는 것이 아닙니다. 항성의 입상 무늬·홍염·광채, 대기 테두리와 노출은 시각화용 표현입니다. 조명은 압축한 거리에서 행성 특징을 보기 위한 설정이며 실제 거리별 광도를 재현하지 않습니다. 지도 원본·출처·라이선스·변환 기록·해시는 `data/planets/`에 동봉하며 생성 행성의 절차적 표면은 유지합니다.

궁수자리 A*의 질량 약 400만 태양질량은 [NASA 블랙홀 자료](https://science.nasa.gov/universe/black-holes/)를 참고합니다. 지평선 반지름은 비회전 슈바르츠실트 모형의 근사입니다. 광선은 등방 좌표의 슈바르츠실트 광학 계량으로 역추적합니다(중점 적분, 최대 256회). 비회전 블랙홀에서 뒤쪽 원반의 렌즈 효과와 중력·도플러 이동을 반영합니다. 표현 기준은 [NASA 시각화](https://svs.gsfc.nasa.gov/13326/)이며 광학 계량은 [Perlick의 중력 렌즈 리뷰](https://link.springer.com/article/10.12942/lrr-2004-9)를 참고합니다. 원반은 ISCO 바깥의 얇고 불투명한 모형으로 색·밝기·난류 무늬는 가시성을 위한 재구성입니다. 카메라에 붙는 고리·호 장식은 사용하지 않습니다. 회전하는 Kerr 시공간, 플라스마, 정밀 복사 전달과 관측 파장별 영상은 계산하지 않습니다. 렌즈 효과는 기존 생성 배경 별과 방향·색이 같은 지도에 적용하며 다른 장면 물체 전체에는 적용하지 않습니다. 유한 적분·화면 해상도로 매우 가는 고차 영상에는 한계가 있습니다. 다른 은하의 중심 블랙홀은 생성 천체로 구분합니다.

지구 하늘에서는 탐사용으로 생성한 별 대신 XHIP의 J2000 좌표·겉보기 등급·B−V 색지수를 사용합니다. [d3-celestial](https://github.com/ofrohn/d3-celestial)의 고정한 버전에서 별과 별자리 자료를 추출했으며 출처와 BSD 라이선스는 `data/NOTICE.txt`, `data/D3-CELESTIAL-LICENSE.txt`에 있습니다. 재생성은 `python3 scripts/prepare-sky-data.py`로 합니다.

J2000 좌표에 IAU 1976 평균 세차를 적용하고 [USNO의 평균항성시](https://aa.usno.navy.mil/faq/GAST)와 [지평좌표 변환](https://aa.usno.navy.mil/faq/alt_az)을 사용합니다. UTC를 UT1의 근사로 사용합니다. 고유운동·연주광행차·대기굴절·날씨·광공해·낮의 밝기 및 달·행성은 계산하지 않는 안내용 별 지도입니다. 별의 크기와 밝기는 보기 쉽게 강조합니다. 망원경 정밀 지향용은 아닙니다.

## 검증 및 GitHub Pages

```sh
npm test
python3 scripts/package.py
```

검증은 생성 결과의 재현성, 태양계 구성, 궤도 주기와 역방향 시간, 확대 좌표계 변환·왕복 경계, 항성시·세차의 공개 기준값, 시간대·서머타임, 별 자료와 행성 지도 파일의 유효성, 왕복 드래그·합쳐진 이동 표본·핀치·취소 뒤 탭 판정을 확인합니다. 블랙홀 광선은 해석적인 포획 경계의 ±0.3% 구간, 충돌 매개변수 보존(오차 0.4% 이내), 원반 교차·위아래 대칭과 도플러 밝기 방향을 검사합니다. `tests/black-hole-preview.html`은 실제 렌더링 모듈의 정면·경사·측면·아래 시점 검수용이고, `tests/appearance-preview.html`은 태양·지구·목성·토성 외관 검수용입니다. `tests/mobile-preview.html`은 375×667·390×844·844×390 크기의 수동 화면 검수용입니다. 실제 휴대폰의 터치·성능 검수를 대신하지는 않습니다. `dist/`는 게시할 파일만 담습니다.

GitHub 저장소의 기본 브랜치를 `main`으로 두고 **Settings → Pages → Source → GitHub Actions**를 선택하면, 포함된 워크플로가 `main` 갱신 시 검사 후 게시합니다. 프로젝트 하위 경로에서도 동작하도록 모든 자원 경로는 상대 경로입니다.
